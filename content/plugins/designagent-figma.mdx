## Release notes

### v0.26.0

- **Chat with Claude inside Figma (beta).** Type in the DesignAgent panel instead of switching
  to the terminal. It runs your own Claude Code, so it uses the plan you already have. Pair the
  panel once with a code from your terminal (the pairing command is Mac-only for now).
- **The panel connects on its own.** No Start button. Setup steps only appear if Claude Code
  can't be found, and the update steps only appear when your plugin is out of date.
- **Your project is remembered.** Pick it once; switch any time from the small menu.
- Claude only edits files in your project if you tick "Let Claude edit my files".

### v0.25.0

- **Link designs to your variables.** Spacing, corner radius, borders, opacity, sizes, text
  styles, colours and shadows can follow your variables. Change the variable and the design
  follows.
- **Export animations as video or GIF (beta).** Animate a frame, then ask Claude to export it.
- **Web pages turn into better Figma layouts.** Rows that wrap in the browser wrap in Figma,
  minimum and maximum sizes carry over, grids keep their real column widths, and items that
  span several columns or rows land where they should.
- Claude can use the custom animation styles saved in your file.

### v0.24.0

- **Images are more reliable.** Formats Figma can't read (WebP, HEIC, AVIF) and oversized
  images are converted for you on Mac, and anything that still can't be placed comes with a
  clear reason.
- **Animations are easier to ask for.** Just say "fade in" or "slide out".
- Removed four features almost nobody used (Lottie import, pattern fills, token export and the
  separate noise tool). Noise and grain are still available as an effect.

### v0.23.0

- **New: `place_svg`, `place_icon`, `place_lottie`** — any SVG (an exported SF Symbol, a brand
  mark) lands as native vectors; Lucide and Material Symbols icons are fetched by name,
  recolored, and sized; a Lottie file becomes one frame of native vectors. No more
  redrawing the arrow.
- **New: `capture_simulator`** (macOS) — screenshots the booted iOS Simulator into Figma as an
  image frame at point size. Flat pixels; for editable layers, use `html_to_design`.
- `html_to_design` fidelity: absolute/fixed children pin where the browser put them;
  `radial-gradient` → native radial; layered backgrounds → stacked fills;
  `backdrop-filter: blur()` → background blur; layer names come from
  `data-name`/`id`/`aria-label`/class, and the root frame takes the `<title>`.
- New nodes auto-place inside Sections (`html_to_design`, `place_image`, `create_*`).
- Renders went from 20s+ to under a second (the font list is cached now);
  `take_screenshot` waits for a paint in progress instead of catching it half-done.
- `html_to_design { path }` also reads HTML from the OS temp dir and the scratchpad.

### v0.22.1

- `html_to_design` paints CSS `background-image: url()` as an image fill (FILL / FIT / TILE);
  `<img>` corner radius carries over.

### v0.22.0

- **New: `claude-design-to-figma` skill** — Claude Design exports HTML but has no Figma
  export. This skill renders each artboard (a `.zip`/standalone export, or a `/design`
  canvas's `.dc.html` files) into editable Figma frames and verifies them by screenshot.
- **`html_to_design` binds to your design system** — solid colors and text that exactly
  match a local color variable, paint style, or text style come out bound to it.
  `useDesignSystem: false` keeps literal values.
- **`html_to_design { path }` inlines relative assets** — `<img src>` and CSS `url()` paths
  resolve against the HTML file's folder.
- `list_variables_and_styles` now returns each variable's default-mode value.
- Onboarding: the Figma panel's Setup card explains what's missing and has copy buttons for the
  two install commands; the session hook links the Community plugin.

### v0.21.0

- `html_to_design`: CSS grid → native Figma grid, `space-around`/`space-evenly`,
  `text-wrap: balance|pretty`, variable-font axes; wrapped text keeps its container width.
- `batch { screenshot }` returns a PNG in the same call; `get_spec { nodeId, depth }`.
- New tools: `rename`, `set_auto_layout`, `set_instance_property`, `create_component`,
  `list_variables_and_styles`; `set_text_style { wrap, variation }`; native fills and effects
  (`set_gradient`, `set_noise`, `set_pattern`, `set_effect`) with the `figma-effects` skill.
- Removed `set_shader`, `list_shaders`, `set_grid`, `apply_fix` (near-zero usage).

### v0.20.0

- **New: `export_asset`** — Claude exports icons, logos, images, and illustrations
  straight from the design into real SVG/PNG files in your project, including
  assets inside nested component instances. Vectors come out as clean SVG,
  images as PNG with transparency intact. No more screenshots-as-assets or
  rebuilt wordmarks.
- Lookups on nested-instance layers fail fast with a clear message instead of
  hanging for 20 seconds.
- Heavy exports are queued, so bursts of screenshots no longer drop the bridge.

### v0.19.0

- New collapsible **Update** card in the panel with the exact update steps
  (`/plugins` → designagent → Update now, then `/reload-plugins`).
- The connected-project state got a proper card treatment.

### v0.18.0

- Anonymous usage telemetry: the MCP server counts tool-call names (never
  design content or parameters) so we know which tools earn their keep.
  Opt out with `DESIGNAGENT_TELEMETRY=0`.
